The bundled USDA generic-food database lives here:

- `usda_foods.tsv.gz` – foods with nutrients per 100 g
- `usda_version.txt` – a version string; changing it makes phones reload the foods

Both are generated by `tools/usda/build_usda_asset.py`, normally through the
"Refresh USDA food data" GitHub Actions workflow. Until it has run, the app works
without generic foods (barcode lookups and your own foods still work).

Source: USDA FoodData Central, public domain (CC0 1.0).
